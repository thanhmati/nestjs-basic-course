## 2. Mẹo Tối Ưu Trải Nghiệm Học Viên (Udemy Experience Tips)

> [!TIP]
> **Tăng tương tác và hoàn thành khóa học:**
>
> 1. Đính kèm file `postman_collection.json` ngay bài học Module 1 để học viên import sử dụng từ sớm.
> 2. Cung cấp file `.env.example` đầy đủ trong mọi branch mã nguồn.
> 3. Tạo sẵn 1 video ngắn hướng dẫn học viên cách dùng Git branch đối chiếu code khi bị bug.
